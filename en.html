Lumen — Privacy Policy

Lumen — Local File Automation (Windows 10/11)

Last updated: 17 August 2026 Application: Lumen — Local Document Filing (Windows 10/11)

1. Summary

Lumen collects no data. The application runs entirely on your device; your file contents, rules and agent history never leave it. We operate no servers, so we have no way to receive, store or share anything that belongs to you.

Network monitoring was removed entirely in v2.33. The application no

longer reads which program is connected to which host, does not open the

system DNS cache and does not measure traffic. The code, the database tables

and the dashboard tab were deleted. This policy described that feature, which

is why it has been updated.

2. What we do not collect

None of the following is collected, transmitted or shared with third parties:

  • File names, file contents, folder structure
  • OCR or AI classification results
  • Usage statistics, feature usage, session duration
  • Crash reports, error logs, diagnostic data
  • Device identifiers, IP address, location, account information

There is no telemetry by design — it is not a setting you switch off; no such code path exists in the application.

3. Where your data lives

Everything is stored only on your own computer:

`` %APPDATA%\Lumen\ config.json settings rules.json your rules lumen.db SQLite: action history, file origins, agent suggestions models\ (optional) local AI model, if you downloaded one Quarantine\ quarantined files ``

Deleting this folder resets the application completely. You can export your settings and rules as a backup file from the dashboard.

4. Internet access: where and why

Lumen works offline. It contacts the internet only in the cases below, and only when you explicitly press a button:

WhenWhereWhat is sent
"Download model pack"github.com (llama.cpp), huggingface.co (model file)A standard download request only. None of your data is sent.
"Check for updates"The same two hosts (version/size query)A version query only. None of your data is sent.
"Add language pack"Microsoft Windows UpdateThe operating system's own install flow; nothing reaches Lumen.

None of these are required; Lumen works fully without them. Outside those three buttons the application has no code path that reaches the internet at all — telemetry_audit.py verifies this on every build, both by scanning the source and by watching the sockets of the running application.

5. AI (OCR and SLM)

  • OCR uses the Windows built-in Windows.Media.Ocr component. Your

documents are processed on your device.

  • The SLM (small language model), if you choose to download it, runs as a

local process bound to 127.0.0.1 (your own machine). Document text never leaves that local process.

  • You can disable AI features entirely in Settings; the rule engine works

without them.

6. Sensitive-folder encryption

If you use the "Sensitive Folders" feature, files are encrypted with Windows DPAPI plus a password you choose. Your password is never stored anywhere and is never transmitted to us; consequently, if you forget it, we cannot recover your files.

7. Third-party software

If you choose to download the model pack, the open-source llama.cpp executable and a language model are downloaded to your device. These components are covered by their own licences and run locally only.

8. Children's privacy

Lumen is not directed at children under 13 and does not knowingly collect data from them (it collects data from no one).

9. Changes

If this policy is updated, the new version ships with the application and the "Last updated" date changes. Beginning to collect data would contradict the product's core design principle and is not planned.
